# Imobiliária Santos

Projeto de uma landing page institucional para uma imobiliária, com foco em apresentar a empresa, seus serviços, corretores e informações de contato.

## Objetivo

Este site tem como finalidade divulgar a marca Imobiliária Santos e apresentar uma proposta visual moderna, clara e profissional para captar clientes interessados em compra, venda e aluguel de imóveis.

## Funcionalidades

- Cabeçalho com navegação para as seções principais
- Banner de destaque com imagem de imóvel
- Seção "Sobre" com apresentação da empresa
- Seção "Serviços" destacando áreas de atuação
- Seção "Corretores" com informações do time profissional
- Seção "Contato" com mapa, e-mails e informações de contato
- Layout responsivo e visual consistente em HTML e CSS

## Arquivos principais

- `index.html`: estrutura e conteúdo do site
- `css/estilo.css`: estilos visuais da interface
- `img/`: imagens utilizadas no layout

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto no navegador.
3. Execute o arquivo `index.html` diretamente

## Observações

Este é um projeto estático, desenvolvido com HTML e CSS puro, ideal para fins de apresentação e aprendizado de estruturação de páginas institucionais.

## Tecnologias utilizadas

- HTML5
- CSS3
